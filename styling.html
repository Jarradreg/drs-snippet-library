Styling guide.

How the exported list is put together.

Every line Event Assister exports is deliberately plain, so it lands in Discord looking exactly the way it looked here. We do support:

  • Mentions, highlighted in blue. With Pings on, each line prints <@Discord ID> and Discord colours the mention for you — no formatting needed on your part.
  • Pings, used sparingly. These notify real people, so the Pings switch is off by default. Turn it on only when the list should actually reach everyone on it.
  • Emojis, even custom ones. Standard emoji and a server’s own custom emoji both survive the copy, in event names and usernames alike.
  • Text styling, like bold, italic, and underline. Anything you type around the list — a heading, a note, a footer — keeps its **, _ and __ markers intact.

Some features might not work

Strikethrough, for example, is something we haven’t really implemented. We leave it out on purpose, because we want the tool to be the easiest thing to run on everyone’s phones and computers without having too much lag.
